# Identidad TWC — procedencia y preservación

Fuente original recuperada de la Library del usuario: `Logotipo minimalista del lobo TWC.png`, guardada idéntica bajo `reference/TWC_IDENTIDAD_CORPORATIVA_ORIGINAL.png`.
